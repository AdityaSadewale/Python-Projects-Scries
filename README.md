🏠 Smart Room Rent Calculator (Python Project)
📌 Project Description


This is a beginner-friendly Python project that helps calculate shared living expenses such as rent, food, and electricity. It also allows adding roommate details and generates a friendly monthly payment message for each person 📩.

🚀 Features
👥 Add multiple roommates (Name, Phone, Email)
💰 Calculate total rent including:
House rent
Food expenses
Electricity bill ⚡
📊 Automatically split the total amount
📱 Generate personalized payment messages for each roommate
😊 Simple and interactive GUI using Tkinter
🛠️ Technologies Used
Python 🐍
Tkinter (for GUI)
📷 How It Works
Enter roommate details (Name, Phone, Email)
Add all roommates
Enter rent, food cost, electricity units, and charge per unit
Click "Calculate & Send"
View each person's share and message in the console
